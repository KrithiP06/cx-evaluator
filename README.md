# CX Evaluator

An LLM-powered web platform that analyzes customer-agent conversations and provides actionable insights to improve customer experience.

## 🚀 Features

- Evaluate customer-agent conversations using AI
- Score key CX metrics from 0–10
- Analyze customer sentiment
- Detect issues in conversations
- Generate actionable recommendations
- Generate an AI-enhanced agent response
- Clean, modern dashboard interface

## 🛠️ Tech Stack

**Backend**
